DashStats

A simple web tool for viewing your DashCraft statistics in one place.

What is DashStats?

DashStats lets you enter your DashCraft User ID and view your account and track statistics without having to manually look through everything.

Simply get your User ID from the Share button on your DashCraft user page, enter it into DashStats, and load your statistics.

Features

* View DashCraft account statistics
* Load your tracks
* View track statistics
* Account status information
* League information
* Simple browser-based interface
* No installation required

How to use

1. Open DashStats.
2. Get your DashCraft User ID using the Share button on your DashCraft user page.
3. Paste the User ID into DashStats.
4. Load the account.
5. Browse your statistics and tracks.
